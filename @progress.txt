## Findings

### Patterns
- Structured plan format uses fenced code blocks for metadata and context (rafa:plan, rafa:context, rafa:stage-context)
- Task declarations (trailing {key=value pairs}) are stripped from all quoted output (prompts, commits, logs)
- Report blocks are YAML-based and contain structured lists for findings, blockers, and bugs
- Three injection modes control task context scope: full (whole plan), stage (plan + stage context), task (single task)
- Unknown rafa:* block kinds are retained and ignored, providing extension points for future phases
- Unknown declaration keys (like skills=) are kept in extras map and don't cause parsing failure
