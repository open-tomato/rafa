- `Bun.YAML.parse`, measured on bun 1.3.14, for any YAML reader here
  (`rafa:report` parser included): empty, whitespace-only, comment-only
  or bare `---` input gives `null`; a multi-document stream, an ARRAY; a
  duplicate key silently keeps the last value; malformed input throws a
  `SyntaxError` naming no line or column; a TAB-indented child does NOT
  throw but parses as a sibling top-level key. `constructor`, `toString`
  and `__proto__` come back as ordinary own keys, so look keys up with
  `Map`/`Set`, never `in` or an object index. Integer-like keys
  enumerate first, so `Object.entries` order is not source order.

- Declare a port interface with PROPERTY signatures
  (`keys: (kind: K) => ...`), not method ones: measured with this repo's
  tsc, a backend whose parameter is narrower than the port's is refused
  under a property signature (TS2322) but silently accepted under a
  method one, whose parameters are checked bivariantly. Use a `type`
  alias for a closed per-kind map: an interface can be widened from
  another file by declaration merging, while re-declaring an alias fails
  with TS2300.
