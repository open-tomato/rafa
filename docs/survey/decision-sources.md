## Tenets

- **a helper and not a hinderer** (`#598:234`)
- **a reminder of steps** (`#598:234`)
- **a shortener of commands** (`#598:234`)
- **a simplifier of tasks** (`#598:234`)
- **Never block** A suspected copy, rollback or fork never refuses a command, halts a loop or fails a sync. rafa is a helper, not a hinderer. (`#754:28`)
- **Always tell** The person sees one warning line where it happens, and `rafa doctor` lists it until it is resolved. (`#754:29`)
- **Say what was observed, never what it might mean** The warning states facts ("this store's counter is at 412; this machine saw the same store id reach 530") and never speculates about tampering, attacks or risk. (`#754:30`)
- **Offer the fix, or the way around** Where one rafa line fixes it, the warning names that line. Where none can, it names the steps, the order, and the reason for each. (`#754:31`)
- **Explain once, in one place** Each warning links to one page that says why this matters (the explainer issue filed beside this spec, later a docs page). (`#754:32`)
